# web — Reduta frontend (scaffolded from M1)

React 19 + TypeScript 5.6 + Vite, React Router 7, TanStack Query/Table/Virtual,
Tailwind 4 + shadcn/ui, `cmdk` (command palette), `dnd-kit` (block drag&drop).
Design tokens and screens per `INSTRUKCJE.md` section 8 (dark-first, dense,
terminal-adjacent). The API client is generated from the backend's OpenAPI spec
(`openapi-typescript`) — the frontend never hand-writes request types.

Intentionally empty at M0: the backend skeleton is the M0 deliverable.
