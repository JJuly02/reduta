CTF platform, working title

A Capture The Flag platform that stays usable at 200 challenges.

Reduta is built for large events where CTFd starts to hurt: bulk actions in the admin panel, a reusable challenge library with revisions, block scheduling, a denormalized live scoreboard, clean import and export, and King of the Hill as a plugin.

Features

Challenge library

Reusable challenges with immutable revisions. Edit creates a new revision, so history and rollback come for free. Embed a pinned revision into an event.

Bulk admin actions

Select by filter, then publish, hide, assign to a block, retag, reschedule, or delete in one step. Reversible actions keep an undo snapshot.

Scheduling and unlocks

Block and challenge availability with RRULE windows. Unlock rules evaluate per team: solved, points, block completion, and time gates.

Live scoreboard

Denormalized scoreboard read straight from a projection, cached, and pushed to clients over WebSocket as solves land.

Import and export

Round-trip an event as JSON with a dry-run plan, or bring challenges across from a CTFd export.

Plugins

Out-of-process plugins over signed webhooks and a narrow token-scoped API, so King of the Hill can be wrapped rather than rewritten.

Stack

Backend: Go, chi, pgx, golang-migrate, asynq, nhooyr websocket, PostgreSQL 16, Redis 7. Frontend: React 19, TypeScript, Vite, TanStack Query. Modular monolith, one static binary, Docker Compose for local runs. A single docker compose up brings up the API, worker, database, cache, and web UI.
